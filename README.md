# EtherCoreLegend

EtherCoreLegend is a distributed, scalable framework that optimizes high-availability auto-scaling, real-time data processing, and robust service manager functionality.

EtherCoreLegend is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/EtherCoreLegend.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
